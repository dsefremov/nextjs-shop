# Тестирование nextjs-shop

Здесь записано только то, что действительно запускалось, с результатами. Время — московское (MSK, UTC+3),
22.11.2026, хост Linux, Docker Compose (`DC="sudo -E docker compose"`), Node 24.22.1, npm 11.21.1.

## Что входит в раунд (`docker/round.sh`)

1. `docker/check-repo.sh` — в git нет `var/`, `.env`, сборки, ключей и литералов паролей/секретов;
2. `npm run lint` (ESLint 9, `--max-warnings=0`), `npm run typecheck` (`next typegen` + `tsc --noEmit`),
   `npm run prisma:validate`;
3. сборка образов `web` и `tools` (`next build` внутри Docker);
4. тестовый PostgreSQL 17 → `npm run test:unit` → `npm run test:db`;
5. PostgreSQL 17 → `prisma migrate deploy` → `npm run db:seed` → пересоздание `web`;
6. Playwright e2e (`npx playwright test --project=e2e`, Chromium, на хосте против http://127.0.0.1:8108).

Любой ненулевой код — раунд красный.
